# Homebrew tap for Dockside

[Dockside](https://github.com/shreyansa98/Dockside) — your Mac's smart second dock: live widgets, Claude built in, picture-in-picture video. Free and open source.

```sh
brew install --cask shreyansa98/tap/dockside
```

Update with `brew upgrade --cask dockside`; uninstall with `brew uninstall --cask dockside` (add `--zap` to also remove settings).

Dockside is in public beta and not yet notarized. If macOS blocks the first launch, run
`xattr -dr com.apple.quarantine /Applications/Dockside.app`.
